# LUNAAA Astro Starter

A working Astro starter based on the generated editorial portfolio preview.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321

## Important
The homepage artwork and card thumbnails are CSS placeholders, not copyrighted game images.
Replace them with your own portfolio images in `/public`.

## Deploy
Build with:

```bash
npm run build
```

You can deploy the generated site to your preferred hosting provider and connect `lunaaa.studio`.
